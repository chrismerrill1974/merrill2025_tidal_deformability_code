# Superseded initial grid analysis

The first 1,100-evaluation suite completed and reproduced deterministically.
Its 18-point pressure grid missed a shallow GR mass maximum just inside the
upper EOS boundary. The largest sampled mass was correctly computed, but
classifying GR as boundary-limited from that coarse grid was insufficient.
Current results add four near-edge points and refine the detected GR turnover.
The original journal/summary, verifier output, independent checks and producing
source snapshots are retained here. They are not current maximum-mass evidence.
Original manifest paths refer to the contemporaneous sources; matching source
bytes for those overwritten scripts are in `source_snapshot`. Current scripts
intentionally reject this run on source-hash mismatch. No failed numerical row
was changed into success. The correction is to sampling and interpretation.
